Hi, I'm Sparks. I do onsite IT in the UK: clients, servers, networks, and web filtering. Away from that I write Windows tools, build in s&amp;box, render, and make fursuit parts and props.

The picture is me. Rikkor is the species. Genju created the characters, and the green one is the one I own. I do the model, the scenes, and the renders.

My main fursona is "Sparks Skywere" a mint green and white Timber Wolf.

These days the programs are mostly C# and C++, with PowerShell still doing the jobs it is good at.

### Right now

- The Windows toolkit on [Skywere Industries](https://www.skywereindustries.com/software/): Classic Launch, maintenance, defrag, partitions, patches, and a server manager that is still being built.
- s&amp;box. A [water system](https://github.com/SparksSkywere/S-box-Water-System), a [dialog editor](https://github.com/SparksSkywere/S-box-Dialog-System), and a first game map.
- The site itself, which is the same work wearing a Windows XP shell.

### The workshop

| Tool | What it does |
| --- | --- |
| [Windows Maintenance](https://github.com/SparksSkywere/WindowsMaintenance) | PowerShell. Runs the cleanup and maintenance jobs. [Page](https://www.skywereindustries.com/software/windowsmaintenance/) |
| [Classic Launch](https://github.com/SparksSkywere/ClassicLauncher) | Runs programs from DOS, 95, 98, 2000, and XP on Windows 10 and 11. [Page](https://www.skywereindustries.com/software/classiclaunch/) |
| [Windows Defrag](https://github.com/SparksSkywere/WindowsDefrag) | Cluster map, layout, SSD and NVMe detection, TRIM. [Page](https://www.skywereindustries.com/software/windowsdefrag/) |
| [Windows Patch Manager](https://github.com/SparksSkywere/WindowsPatchManager) | Scans what is installed and applies the updates. [Page](https://www.skywereindustries.com/software/windowspatchmanager/) |
| [Partition Manager](https://github.com/SparksSkywere/WindowsPartitionManager) | Inspect the disks, queue the changes on a map, then apply them. [Page](https://www.skywereindustries.com/software/partitionmanager/) |
| [Windows Cleaner](https://github.com/SparksSkywere/WindowsCleaner) | Cleanup and a bit of optimisation. [Page](https://www.skywereindustries.com/software/windowscleaner/) |
| [Image Organiser](https://github.com/SparksSkywere/ImageOrganiser) | Finds the same photo on every drive, even when the name or the size changed. [Page](https://www.skywereindustries.com/software/imageorganiser/) |
| [Data Broker Fingerprint](https://github.com/SparksSkywere/DataBrokerFingerprint) | Local and session-only. Shows where your details are published, so you can ask for them to come down. [Page](https://www.skywereindustries.com/software/databrokerfingerprint/) |
| [Server Manager](https://github.com/SparksSkywere/servermanager) | Still in development. [Page](https://www.skywereindustries.com/software/servermanager/) |

The older PowerShell scripts are in the repos as well. [D&amp;D character creator](https://github.com/SparksSkywere/DandDPowershellCharacterCreator), driver lister, watchdog, a few game-server link scripts.
